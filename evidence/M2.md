# Gate M2 · flota y sesiones, sin escribir nada

**Exigía:** que la sesión activa no dependa de los resultados de una búsqueda, que dos selecciones
rápidas dejen un único workspace coherente, que los datos viejos sigan siendo usables y que no
haya Dexie, Zustand ni MCP en el navegador.

## Identidad de workspace

```
npx vitest run --project unit apps/core/test/run-state.test.ts
→ 13 passed
```

Abrir dos veces la misma sesión devuelve el mismo workspace —es idempotente por `SessionRef`—, y
el alias `local` que usa el índice se normaliza al bastión en el límite de entrada: no aparece en
ninguna fila de la base.

## Buscar no cambia nada

```
npx playwright test -g "flujo 1"
```

Filtrar reduce la lista y deja intacto lo demás; abrir es la única acción que cambia de contexto,
y lleva a una URL propia.

## El índice viejo sigue sirviendo

```
npx vitest run --project integration tests/integration/sse-and-boundary.test.ts -t "índice"
```

Con el índice caído, la lista conserva las sesiones anteriores, se marca `stale`, la frescura por
host dice cuál falló y con qué error, y la salud queda `degraded` con la base en `ok`. Ninguna
pantalla se vacía por eso.

## Nada de lo que se retiró volvió

```
grep -rE "dexie|zustand|indexedDB|/mcp" apps/web/src | grep -v localStorage
→ sin coincidencias
```

El único almacenamiento del navegador es un espejo del borrador en `localStorage`, y sólo como red
de seguridad de los últimos segundos: al reabrir gana lo que diga el servidor.
